# Biblioteca Programación

## Core Rule

**Primero el fundamento gratis en español, después lo avanzado.**

## When to Use

- Aprender un lenguaje desde cero o subir de nivel.
- Recomendar material de estudio serio y gratuito.
- Preparar prueba o entrevista técnica.

## Process

1. **Elija ruta**
   - Base: algoritmos y Git primero, lenguaje después.
   - Fuente principal: librosgratis.dev y midudev/libros-programacion-gratis en GitHub.
2. **Por lenguaje**
   - JavaScript: Eloquent JS + javascript.info + Full Stack Open.
   - Python: Python para todos + tutorial oficial en español.
   - TypeScript: libro de Basarat en español + manual oficial.
   - SQL: manual de Jorge Sánchez + diseño de Jordi Casas.
   - Git: Pro Git + guía sencilla de Roger Dudler.
   - Docker: Docker en español de Bruno Cascio.
   - Rust: libro oficial en español + Comprehensive Rust de Google.
3. **Estudie**
   - 1 capítulo con ejercicios antes de pasar al siguiente. Código todos los días.

## Output Contract

Entregue: ruta de 3 recursos en orden con link y qué logra con cada uno.
