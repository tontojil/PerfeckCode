# Biblioteca Programación

## Core Rule

**Primero el fundamento gratis en español, después lo avanzado.**

## When to Use

- Aprender un lenguaje desde cero o subir de nivel.
- Recomendar material de estudio serio y gratuito.
- Preparar prueba o entrevista técnica.

## Process

1. **Elija ruta**
   - Base: algoritmos y Git primero, lenguaje después.
   - Fuente canónica: https://github.com/midudev/libros-programacion-gratis (115 recursos en 32 secciones) y web https://librosgratis.dev
2. **Por lenguaje (selección mínima con enlaces exactos)**
   - JavaScript: https://librosgratis.dev/books/javascript-elocuente-cuarta-edicion.pdf + https://es.javascript.info/ + https://fullstackopen.com/es/
   - Python: https://librosgratis.dev/books/python-para-todos.pdf + https://docs.python.org/es/3/tutorial/ + https://librosgratis.dev/books/python-pensar-programador.pdf
   - TypeScript: https://github.com/melissarofman/typescript-book + https://librosgratis.dev/books/typescript-aprendizaje.pdf
   - SQL: https://jorgesanchez.net/manuales/sql/intro-sql-sql2016.html + https://librosgratis.dev/books/bases-datos-diseno-introduccion.pdf + https://librosgratis.dev/books/sql-apuntes-basicos.pdf

## Ejemplo mínimo

Ruta de 3 pasos para Python desde cero, con qué logra cada recurso:

1. `Python para todos` — https://librosgratis.dev/books/python-para-todos.pdf — instala Python, tipos, condicionales y bucles. Logro: escribir 10 scripts de consola sin errores de sintaxis.
2. `Tutorial oficial Python es` — https://docs.python.org/es/3/tutorial/ capítulos 3 al 5 — funciones, listas y diccionarios. Logro: resolver 5 ejercicios con funciones y pruebas manuales.
3. `Piense en Python` — https://librosgratis.dev/books/python-pensar-programador.pdf capítulos 1 al 4 — pensamiento algorítmico. Logro: explicar con sus palabras qué hace cada programa y preparar una prueba técnica básica.

```text
Semana 1: capítulos 1-3 de (1) + 1 script diario.
Semana 2: tutorial oficial (2) + reescribir 3 scripts con funciones.
Semana 3: capítulos 1-4 de (3) + mini proyecto consola de 100 líneas.
```

## Guías de profundización sugeridas

- Valide nivel antes de recomendar: si no maneja Git básico, ponga Git primero.
- Combine un libro PDF con una referencia viva (docs oficiales) y un curso con ejercicios.
- Para entrevistas, cierre con 20 ejercicios de lógica del libro elegido antes de pasar a framework.

## Output Contract

Entregue: ruta de 3 recursos en orden con link y qué logra con cada uno.

### Checklist de verificación

- [ ] La ruta tiene 3 recursos en orden con enlace exacto y verificable.
- [ ] Cada recurso indica qué logra el estudiante al terminarlo.
- [ ] Se consultó `librosgratis.dev` o el repo `midudev/libros-programacion-gratis` para el enlace.
- [ ] Se incluye al menos una fuente oficial (docs o tutorial mantenido).
- [ ] No se recomiendan recursos de pago como paso obligatorio.
- [ ] El plan incluye práctica diaria con ejercicios, no solo lectura.
