# Biblioteca Programación

## Core Rule

**Primero el fundamento gratis en español, después lo avanzado.**

## When to Use

- Aprender un lenguaje desde cero o subir de nivel.
- Recomendar material de estudio serio y gratuito.
- Preparar prueba o entrevista técnica.

## Process

1. **Elija ruta**
   - Base: algoritmos y Git primero, lenguaje después.
   - Fuente canónica: https://github.com/midudev/libros-programacion-gratis (115 recursos en 32 secciones) y web https://librosgratis.dev
2. **Por lenguaje (selección mínima con enlaces exactos)**
   - JavaScript: https://librosgratis.dev/books/javascript-elocuente-cuarta-edicion.pdf + https://es.javascript.info/ + https://fullstackopen.com/es/
   - Python: https://librosgratis.dev/books/python-para-todos.pdf + https://docs.python.org/es/3/tutorial/ + https://librosgratis.dev/books/python-pensar-programador.pdf
   - TypeScript: https://github.com/melissarofman/typescript-book + https://librosgratis.dev/books/typescript-aprendizaje.pdf
   - SQL: https://jorgesanchez.net/manuales/sql/intro-sql-sql2016.html + https://librosgratis.dev/books/bases-datos-diseno-introduccion.pdf + https://librosgratis.dev/books/sql-apuntes-basicos.pdf
   - Git: https://librosgratis.dev/books/git-pro.pdf + https://rogerdudler.github.io/git-guide/index.es.html + https://esparta.github.io/gitimmersion-spanish/
   - Docker: https://github.com/brunocascio/docker-espanol + https://librosgratis.dev/books/docker-introduccion.pdf
   - Rust: https://book.rustlang-es.org + https://google.github.io/comprehensive-rust/es/ + https://librosgratis.dev/books/rust-aprendizaje.pdf
   - Linux: https://debian-handbook.info/browse/es-ES/stable/ + https://es.wikibooks.org/wiki/El_Manual_de_BASH_Scripting_B%C3%A1sico_para_Principiantes
   - React: https://librosgratis.dev/books/react-aprendiz-maestro.pdf + https://www.reactjs.wiki/ + https://leanpub.com/read/react-redux
   - IA: https://iaarbook.github.io/
   - Scrum: https://librosgratis.dev/books/guia-scrum-european.pdf + https://librosgratis.dev/books/scrum-y-xp-desde-las-trincheras.pdf
3. **Estudie**
   - 1 capítulo con ejercicios antes de pasar al siguiente. Código todos los días.

## Output Contract

Entregue: ruta de 3 recursos en orden con link y qué logra con cada uno.
