# Ejemplo: input vago -> prompt mejorado

## Input vago
> "Hazme una pagina bonita para mi cafeteria con menu y fotos"

## Prompt mejorado
Landing de cafeteria de barrio, invita a visitar y ver carta.

**PLATFORM:** Web, Desktop-first (responsive a Mobile con drawer).

**DESIGN SYSTEM:** No incluir colores ni fuentes en el prompt.
Ya aplicados a nivel proyecto via usa stitch-sistema-diseno.

**LAYOUT:**
1. **Header:** sticky navigation bar with centered logo, links Carta/Galeria/Contacto.
2. **Hero Section:** headline "Cafe de especialidad", subtext horario, primary CTA pill "Ver carta".
3. **Primary Content Area:** card grid 3 columnas (Espresso, Filtrados, Dulces) con foto, precio; masonry image grid con captions del local.
4. **Footer:** footer columns (contacto, horario, redes) + copyright.

**PAGE STRUCTURE:** header, hero, features (carta), gallery, testimonials, footer.
Iterar con edits pequenos tras generar.
